USB / BLE 双模键盘使用说明

行为
1. 上电后同时等待 USB 主机识别和蓝牙连接，保留原来的 NFC 蓝牙配对功能。
2. USB 主机完成 SET_CONFIGURATION 后，有线输入优先；蓝牙可以保持连接，但不接收普通按键。
3. 只接充电器、充电线或 USB 未完成枚举时，不抢占蓝牙。
4. 已枚举的 USB 主机空闲挂起时保留有线优先，按键报告进入队列。
   主机启用远程唤醒后，按键触发 USB 唤醒；恢复后按原顺序发送按下和松开，避免丢掉首次触摸。
   主机未允许唤醒时，不强制发送唤醒信号；主机主动恢复后继续发送。
5. 检测到 USB 断开或总线复位后，使用已连接且启用 HID 通知的蓝牙设备，否则继续等待。
   切换时释放旧主机按键，清空历史事件。USB 再接入需要重新枚举后才能抢占蓝牙。
   切换时正在触摸的按键需要松开后重新触摸，避免旧按键落到另一台设备。
6. 保留原项目的触摸组合键习惯：先触摸 Shift/Ctrl/Win/Alt，再触摸普通键。
   Fn 功能仍与原项目一样尚未定义，不会把 Fn 值写入 HID 保留字节。

硬件
按照此 PCB 原理图，使用 CH585 的 USBHS 控制器：PB12 = U2D-，PB13 = U2D+。
USBHS 控制器配置为 12Mbps 全速模式，足够传输键盘报告。
不使用 PB10/PB11 的另一套 USB 控制器。需要 USB 数据线和支持 USB 主机的设备。
通过 USB 主机完成 SET_CONFIGURATION 判断有线身份；充电器仅供电、不枚举，不进入有线模式。
当前原理图无单独的 VBUS 检测输入。断开依据 USBHS 链路状态，挂起不清除枚举状态。
若在电脑休眠期间拔线，而控制器仍保持挂起标志，仅靠这些状态不能可靠区分拔线与休眠。
这一边界需要实机验证；需要严格区分时，应增加 VBUS 检测输入（分压/保护后接到空闲 GPIO）。
远程唤醒使用 CH585 USBHS 的 R8_USB2_WAKE_CTRL，硬件生成并结束唤醒信号。
检测到挂起后至少等待 5ms，再按主机授权发出一次唤醒。HAL_SLEEP 仍为 FALSE，触摸扫描持续运行。
USB 标识采用 WCH 官方 CompoundDev 示例的开发 VID/PID；商业发行时应使用自有标识。

编译与烧录
在 MRS2 打开 PCB_Bluetooth_Keyboard.wvproj，选择 obj 配置并重新编译。
新增 APP/usb_keyboard.c 和 APP/keyboard_transport.c 应出现在构建日志中。
固件输出：obj/PCB_Bluetooth_Keyboard.hex。
烧录方式沿用原项目。固件没有自动写入设备，需要自行通过 ISP 或下载器烧录。
tests 目录已在 MRS 构建配置中排除，不应编入设备固件。

主要文件
APP/usb_keyboard.c：USB 描述符、EP0 枚举与 HID 控制请求、EP1 键盘上报。
APP/keyboard_transport.c：有线优先、连接切换、报告队列和发送忙时重试。
APP/hidkbd.c：复用原键位映射；按键处理持续运行，不依赖蓝牙连接来启动。

软件验证
tests/run-tests.ps1 使用电脑上的 GCC 执行主机模拟测试。
覆盖 USB 描述符、地址和配置、HID 协议及 LED 请求、按下/松开顺序、USB 优先、
复位重枚举、USB 挂起和恢复、蓝牙重连、报告缓冲区压力与忙时重试。
增加空闲 60 秒后快速触摸、READY 暂时降低时不清掉挂起配置、缺少恢复中断、
主机启用/禁用远程唤醒、唤醒延时及单次信号、充电器不枚举和断开后重新识别的测试。
从 APP/hidkbd.c 提取实际按键处理分支进行主机编译，验证 Esc、按键释放、组合键及背压。
模拟测试不能证明实际 USB 电气信号和主机兼容性，需进行下面的实机检查。

实机检查
1. USB 接电脑：设备管理器出现 HID 键盘，在输入框中测试字母、退格、方向键及组合键。
2. 手机保持蓝牙连接，USB 接电脑：按键只输入电脑，手机不应出现字符。
3. 电池供电时拔 USB：按键恢复输入手机。未连接蓝牙时应等待连接。
4. USB 接充电器：手机仍能通过蓝牙接收按键。
5. 在按键触摸期间插拔 USB：松开并重新触摸，确认无连续重复或卡键。
6. USB 连接后空闲 1 分钟、5 分钟和 15 分钟，再快速触摸字母键，确认首次输入及随后输入正常。
   电脑休眠和恢复：主机允许键盘唤醒时测试按键唤醒；不允许时主动恢复电脑，再检查键盘。
   可在设备管理器的键盘“电源管理”页查看“允许此设备唤醒计算机”（是否提供取决于主机）。
   空闲及休眠状态分别测试拔下 USB 后改接充电器，确认手机可继续通过 BLE 接收按键。
7. 无蓝牙配对记录时，通过 NFC 配对，确认原功能正常。
